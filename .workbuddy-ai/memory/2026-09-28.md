## 完成 Issue #2：支持关闭「还原屏幕」按钮

- 需求：播放器中央的「还原屏幕」按钮容易触发且遮挡画面，希望可以关闭。
- 方案（已与用户确认）：在控制面板加开关，默认开启（保持原行为）。
- 实现：
  - 新增全局变量 `resetButtonEnabled`，读取 `localStorage['nbs_resetButtonEnabled']`（非 'false' 即开启）。
  - `updateResetButtonVisibility()` 增加开关判断，关闭时移除 `.show` 类。
  - 面板 HTML 新增一行开关 `<input class="nbs-reset-toggle">`，切换时写 localStorage + `updateResetButtonVisibility()` + Toast 反馈。
  - CSS 重构：`.nbs-memory-row/.nbs-memory-toggle/.nbs-memory-slider` → 通用 `.nbs-toggle-row/.nbs-switch/.nbs-switch-slider`，两行开关共用。
  - 版本 6.2.2 → 6.3.0，同步更新 `@description` 与 README。
- 提交：`f93f944`（commit message 带 `Closes #2`），已 push 到 origin/main，issue 被 GitHub 自动关闭并附说明留言。
